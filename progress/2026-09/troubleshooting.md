| **`ValueError: Graph must have an entrypoint` 컴파일 실패** | 그래프 빌더 구성 중 `START` 노드에서 첫 번째 실행 노드(`router`)로 연결되는 진입 엣지가 누락됨 | `builder.add_edge(START, "router")`를 명시적으로 선언하여 그래프 진입점 지정 |
| **추론형 모델(Thinking Model)의 토큰 고갈 및 빈 응답(`content=''`) 반환** | 모델이 생성 토큰 전체를 내부 `<think>` 추론에 소진하여 한도에 도달했고, 기존 순수 파이썬 루프에 존재하던 '빈 응답 시 재요청 폴백'이 LangGraph 마이그레이션 과정에서 누락됨 | `ChatOllama` 파라미터에 `reasoning=False`를 명시하여 추론 모드를 API 수준에서 끄고, `settings.py`의 `num_predict`를 2048로 확장한 뒤 `engine.py` 노드에 빈 응답 감지 시 최종 답변을 1회 재요청하는 폴백 로직 추가 |
