## 2026-09-13

| 문제 현상 | 원인 분석 | 해결 방법 |
| :--- | :--- | :--- |
| **도구 호출 실패 위험** | 파이썬 함수(`export_search_results_to_file`)에는 기본 파일명이 정의되어 있으나, 스키마에는 `dest_path`가 `required`로 지정되어 인자 생략 시 유효성 검증 실패 가능성 존재 | `FILES_SCHEMAS`에서 `required` 항목을 비워 모델이 인자를 생략해도 기본 경로로 안전하게 폴백되도록 일치화 |
| **탐색 중단 상태 모호성** | 단순 결과 수량 초과(`len(matches) >= max_results`)와 실제 5만 개 스캔 한도 도달(`scanned_count >= MAX_SCAN_LIMIT`)이 동일한 `hit_limit` 플래그로 묶여 반환됨 | `hit_scan_limit`과 `hit_max_results`로 반환 플래그를 명확히 분리하여, 모델이 소량 탐색 성공 상태를 탐색 한계로 오인하지 않도록 보정 |
| **프롬프트 오염 위험** | 상위 모델의 검수 프롬프트 생성 과정에서 마크다운 본문에 출처 태그(`[cite: 2]`)가 포함되어 로컬 모델이 이상 출력을 학습할 위험 발생 | 로컬 9B~14B 모델 환경에 맞춰 출처 표기 태그를 완전히 제거한 순수 마크다운 텍스트로 정제하여 적용 |
